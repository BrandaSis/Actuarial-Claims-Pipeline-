# Actuarial Claims Pipeline

An end-to-end actuarial data engineering project built with Python, SQL, PostgreSQL, and Power BI.

## Goals

- Read raw insurance policy and claims data
- Validate and clean incoming records
- Load data into PostgreSQL
- Generate actuarial reporting metrics
- Visualize portfolio performance in Power BI

## Tech Stack

- Python
- Pandas
- SQL
- PostgreSQL
- Git & GitHub
- Power BI
